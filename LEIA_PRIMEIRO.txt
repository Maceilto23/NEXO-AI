NexoAI — Projeto Completo e Onde Salvar Cada Arquivo

#1. GITHUB — repositório principal
Suba para a RAIZ do repositório:
- `.github/` → GitHub Actions para compilar APK
- `android/` → projeto Android
- `server/` → backend que será implantado no Render
- `render.yaml` → configuração do serviço Render
- `.gitignore`

Não coloque chaves OpenAI no GitHub.

#2. RENDER — servidor da API
O Render deve usar a pasta `server/` como backend (ou o `render.yaml` da raiz conforme configurado).
Arquivos do servidor:
- `server/api.php`
- `server/Dockerfile`
- demais arquivos existentes em `server/`

No Render > Environment, cadastre:
- `OPENAI_API_KEY` = uma NOVA chave OpenAI
- `APP_TOKEN` = o mesmo token privado configurado no aplicativo
- `OPENAI_MODEL_FAST` = `gpt-5.6-luna`
- `OPENAI_MODEL_BALANCED` = `gpt-5.6-terra`
- `OPENAI_MODEL_SMART` = `gpt-5.6-sol`
- `MAX_CHARS` = `12000`

A API esperada é:
`https://nexoai-api.onrender.com/api.php`

#3. INFINITYFREE — htdocs
Abra a pasta `htdocs/` deste pacote e envie SOMENTE O CONTEÚDO dela para:
`nexoai.page.gd/htdocs/`

Não envie para htdocs:
- `.github`
- `android`
- `server`
- `Dockerfile`
- `render.yaml`
- `.env`
- chave OpenAI

#4. APK
No GitHub:
Actions → Build Nexo AI APK → Run workflow.
O APK compilado ficará nos Artifacts da execução.

#Sequência recomendada
1. Subir o projeto para o GitHub.
2. Conectar/configurar o Render.
3. Cadastrar as variáveis de ambiente no Render.
4. Fazer Deploy no Render.
5. Abrir `https://nexoai-api.onrender.com/api.php` e confirmar JSON/status online.
6. Confirmar que o Android aponta para essa URL e usa o mesmo APP_TOKEN.
7. Rodar GitHub Actions e baixar o APK.
8. Instalar/testar o APK.
9. Se desejar o site, enviar apenas `htdocs/*` ao InfinityFree.

SEGURANÇA: a chave OpenAI compartilhada anteriormente deve ser revogada e substituída por uma nova.
